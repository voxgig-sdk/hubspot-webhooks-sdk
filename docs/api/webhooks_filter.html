filter.conditions[].value string No A string representing the value to be compared against the specified property when using single-value operators.
filter.conditions[].values array of string No An array of strings used to specify multiple values for comparison when using operators that support multiple values, such as 'IN' or 'NOT_IN'.
subscriptionId integer (int64) Yes The unique identifier of the subscription to which the filter will be applied. It is an integer formatted as int64.
