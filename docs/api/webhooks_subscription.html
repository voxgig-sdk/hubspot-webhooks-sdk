create

POST /app-webhooks/2026-09/{appId}/subscriptions

Operation ID: post-/app-webhooks/2026-09/{appId}/subscriptions_create.

Authentication: oauth2 (oauth2).

Parameters

| Parameter | In | Type | Required | Description | | --- | --- | --- | --- | | appId | path | integer (int32) | Yes | The unique identifier of the app for which the webhook subscription is being created. |

Request body

application/json

Property Type Required Description
active boolean Yes A boolean indicating whether the subscription is active.
eventType enum: company.associationChange, company.creation, company.deletion, company.merge, company.propertyChange, company.restore, ... Yes A string representing the type of event to subscribe to. Valid values include various property changes, creations, deletions, merges, restorations, association changes, and event completions.
eventTypeName string No A string providing a human-readable name for the event type.
objectTypeId string No A string representing the ID of the object type associated with the subscription.
propertyName string No A string indicating the specific property name related to the event type, if applicable.
