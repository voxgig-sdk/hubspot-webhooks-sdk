API reference

The API reference covers all entities. The tools section lists the operations this server exposes.

Tools

hubspot-webhooks_list

List records for an entity.

{
  "type": "object",
  "required": [
    "entity"
  ],
  "properties": {
    "entity": {
      "type": "string",
      "description": "basic | webhooks_batch_response_journal_fetch | webhooks_batch_response_subscription | webhooks_crm_object_snapshot_batch | webhooks_filter | webhooks_setting | webhooks_snapshot_status | webhooks_subscription | webhooks_subscription_response_1"
    },
    "query": {
      "type": "object",
      "description": "Optional match fields for the selected entity."
    }
  }
}

Supported entities: webhooks_subscription, webhooks_subscription_response_1.

hubspot-webhooks_load

Load one record for an entity.

{
  "type": "object",
  "required": [
    "entity"
  ],
  "properties": {
    "entity": {
      "type": "string",
      "description": "basic | webhooks_batch_response_journal_fetch | webhooks_batch_response_subscription | webhooks_crm_object_snapshot_batch | webhooks_filter | webhooks_setting | webhooks_snapshot_status | webhooks_subscription | webhooks_subscription_response_1"
    },
    "query": {
      "type": "object",
      "description": "Optional match fields for the selected entity."
    }
  }
}

Supported entities: basic, webhooks_batch_response_journal_fetch, webhooks_filter, webhooks_setting, webhooks_snapshot_status, webhooks_subscription, webhooks_subscription_response_1.
